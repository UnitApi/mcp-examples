# Raspberry Pi Control Examples

This directory contains examples demonstrating Raspberry Pi GPIO and hardware control using the MCP Hardware Project.

## Examples

### rpi_control.py

This example demonstrates basic GPIO control on a Raspberry Pi, showing how to interact with pins, read inputs, and control outputs.

**Features:**
- GPIO pin configuration
- Reading digital inputs
- Controlling digital outputs
- PWM control examples
- Sensor reading examples

**Usage:**
```bash
python rpi_control.py
```

**Requirements:**
- Raspberry Pi hardware
- MCP hardware package: `pip install -e .`
